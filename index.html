PANDUAN PEMBELIAN

Cara Order Game Edukasi

Langkah mudah membeli dan langsung memainkan game pembelajaran digital kami.

1

Pilih Game Edukasi

Telusuri katalog produk di atas. Pilih game yang sesuai usia dan kebutuhan belajar siswa atau anak Anda.

2

Klik Pesan Sekarang

Tekan tombol hijau pada game pilihan Anda untuk memunculkan jendela kode pembayaran QRIS dan rincian harga.

3

Scan QRIS & Bayar

Scan kode QRIS menggunakan e-wallet (DANA, GoPay, OVO, ShopeePay) atau m-Banking apa saja sesuai nominal.

4

Terima Akses via WhatsApp

Kirim screenshot bukti bayar via tombol WhatsApp. Admin langsung mengirimkan link game siap main tanpa instalasi!
