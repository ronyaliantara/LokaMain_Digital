Ganti soal sendiri, sesuai materi Anda

Semua game punya Mode Guru. Soal bisa diketik langsung di game atau diisi lewat Excel, tanpa perlu menghubungi admin.

  1. Buka game dari link Anda

    Pakai link yang dikirim admin lewat WhatsApp, di laptop, Smart TV, atau IFP.

  2. Klik tombol Guru di bagian atas layar

    Tulisannya 🔐 Guru, ✏️ Guru, atau ⚙️ Guru, tergantung gamenya.

  3. Masukkan PIN 1234

    Lalu klik Buka. Daftar soal (bank soal) akan tampil.

  4. Ubah soalnya

    ➕ Tambah Soal untuk soal baru, ✏️ untuk mengedit, 🗑️ untuk menghapus. Banyak soal sekaligus? Pakai Excel (lihat di bawah).

  5. Klik ✕ Tutup lalu mulai main

    Soal langsung tersimpan otomatis, tidak perlu menekan simpan lagi.

Isi banyak soal sekaligus lewat Excel

  1. Di Mode Guru, klik 📄 Template Excel. File contoh akan terunduh.
  2. Buka di Excel, WPS, atau Google Sheets. Isi satu soal per baris: Kategori, Pertanyaan, Pilihan A sampai D, Kunci Jawaban (cukup huruf A/B/C/D), dan Penjelasan (boleh kosong).
  3. Simpan sebagai file .xlsx.
  4. Kembali ke Mode Guru, pilih Impor: Ganti semua (soal lama diganti) atau Impor: Tambahkan (soal lama tetap ada), lalu klik 📥 Impor Excel dan pilih file tadi.
  • Soal tersimpan di perangkat yang dipakai. Mengubah soal di laptop tidak otomatis pindah ke IFP. Klik 📤 Ekspor Excel di laptop, lalu Impor Excel di IFP.
  • Simpan file Excel Anda sebagai cadangan. Kalau data browser dihapus, soal bisa dimasukkan lagi dalam sekali impor.
  • Pakai template dari game yang sama. Pilihan C dan D boleh dikosongkan untuk soal 2 pilihan. Beberapa game, seperti Ekspedisi Kapal dan Ular Tangga, memang hanya memakai 2 pilihan.
  • Fitur Excel butuh internet. Tombol 🔄 Soal Bawaan mengembalikan soal awal dari kami.

Setelah link diterima, buka game lalu klik tombol Guru di bagian atas, masukkan PIN 1234.

Cara 1: Ketik langsung di game
  1. Klik ➕ Tambah Soal untuk soal baru.
  2. Klik ✏️ untuk mengubah soal, 🗑️ untuk menghapus.
  3. Klik Simpan Soal, lalu ✕ Tutup. Soal tersimpan otomatis.
Cara 2: Unduh, ubah di Excel, lalu impor
  1. Unduh: klik 📄 Template Excel (file contoh kosong) atau 📤 Ekspor Excel (berisi soal yang sudah ada di game).
  2. Ubah: buka file di Excel, WPS, atau Google Sheets. Satu baris = satu soal. Isi Pertanyaan, Pilihan A–D, dan Kunci Jawaban cukup huruf A/B/C/D. Simpan sebagai .xlsx.
  3. Impor: kembali ke Mode Guru, pilih Impor: Ganti semua atau Impor: Tambahkan, lalu klik 📥 Impor Excel dan pilih file tadi.
Pindah ke IFP / laptop lain
  1. Soal tersimpan di perangkat yang dipakai saja.
  2. Di perangkat lama klik 📤 Ekspor Excel, kirim filenya (WA, flashdisk, atau Drive).
  3. Di IFP / perangkat baru buka game, masuk Mode Guru, lalu 📥 Impor Excel.
